# 🚀 Docker Compose Learning Notes

## 📌 Project Goal

Learn how to manage multi-container applications using Docker Compose by building a real-world setup with:

- Flask Application
- Redis
- NGINX
- Docker Compose

# 🧠 Why Docker Compose?

Running one container manually is easy.But real applications contain multiple services:

- Frontend
- Backend
- Database
- Cache
- Authentication
- Messaging Services
Managing everything manually using multiple `docker run` commands becomes difficult.
Docker Compose solves this problem.

# ⚡ What is Docker Compose?

Docker Compose is a tool used to:

✅ Manage multiple containers  
✅ Create networking automatically  
✅ Handle dependencies  
✅ Simplify development workflow  
using a single file:docker-compose.yml

2. Service Discovery
3.depends_on

NGINX distributes requests across multiple Flask containers.

Build & Run Containers

**Key Takeaways
•	Docker Compose simplifies multi-container applications
•	Service names work as internal hostnames
•	Docker automatically creates networking
•	Logs are essential for debugging
•	NGINX can be used as reverse proxy and load balancer

** Final Insight
Docker Compose is the foundation of modern:
•	DevOps workflows 
•	Microservices 
•	Backend infrastructure 
•	Containerized development environments 
It allows developers to manage entire application stacks using:
